# Special Delivery for Lily 💖

Pure CSS version — no external images used for the gift box, flowers, or envelope.
Everything is recreated with code so animations (lid lift, ribbon fade, envelope flap open, etc.) work smoothly.

## How to open
Just open `index.html` on your phone (best in Safari).

## Music
Put your “Slide Away – Oasis” mp3 inside the `sounds/` folder and name it `ambient.mp3`.
Volume is already set very soft.

## Flow
1. iPhone notification slides down (“Special Delivery”)
2. Accept → pink gift box appears
3. Tap box → ribbon disappears + lid lifts up → two gifts appear
4. Tap flower → zooms + butterflies + sparkles
5. Tap envelope → flap opens → letter zooms in
6. After reading → Continue → cute receipt

Enjoy 💕
